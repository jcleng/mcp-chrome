Chrome MCP Server

把你自己日常使用的 Chrome 变成 MCP 服务器 —— 保留登录状态、扩展与配置，让任意支持 MCP 的客户端直接操作浏览器。

扩展下载（最新构建）
版本 1.0.0 · Chrome MV3
下载 .zip

安装

  1. 下载并解压上面的 zip
  2. 打开 Chrome，地址栏输入 chrome://extensions/
  3. 右上角开启「开发者模式」
  4. 点击「加载已解压的扩展程序」，选择解压后的文件夹
  5. 安装 mcp-chrome-bridge 并注册 Native Host（见下方）

连接 Native Server

npm install -g mcp-chrome-bridge
mcp-chrome-bridge register

扩展安装后在弹窗里填入 Native Server 端口（默认 12306），点击连接测试。

本版本要点

  • chrome_read_page 改为紧凑大纲输出：每行一个元素，可交互节点带 [ref=ref_N]，静态文本合并为 - text:，同样页面体积下降约 80–90%
  • 新增 chrome_find_by_text：按页面上的文字直接定位元素并返回 ref， 命中优先取最内层元素、再上溯到可操作控件（label → 对应 input/button）， 支持 exact / tag / maxResults 与模糊兜底
  • 两者返回同一套 ref，可直接传给 chrome_click_element / chrome_fill_or_select / chrome_computer
